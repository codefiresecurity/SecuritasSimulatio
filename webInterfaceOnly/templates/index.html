Available Commands

Use these commands to interact with the MITRE ATT&CK database:

  • ttp id <ID> Get details for a specific TTP by ID (e.g., ttp id T1059)
  • ttp search <term> Search TTPs by name or keyword (e.g., ttp search phishing)
  • ttp detail <ID> Get detailed info for a TTP (e.g., ttp detail T1059)
  • recommend <ID(s)> Recommend log sources for TTPs, supports comma-separated list (e.g., recommend T1059, T1589)
  • group_ttps <Group ID(s)> List TTPs used by groups, including linked software/campaigns, supports comma-separated list (e.g., group_ttps G0007, G0059)

Note: IDs can be TTPs (Txxxx), Groups (Gxxxx), Software (Sxxxx), or Campaigns (Cxxxx).
