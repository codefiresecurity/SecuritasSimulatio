Available Commands

Use these commands to interact with MITRE ATT&CK data or create tabletop exercises.

  • create tabletop Start a new tabletop exercise.
  • ttp id Look up a technique by ID (e.g., T1059).
  • ttp search Search techniques by name or description.
  • ttp detail Get detailed info for a technique.
  • group Search for a group (e.g., G0027).
  • software Search for software (e.g., S0002).
  • campaign Search for a campaign (e.g., C0001).
  • graph Generate a relationship graph for an ID.
  • recommend Get log source recommendations for TTPs.
  • group_ttps List TTPs used by groups.
  • clear Clear your conversation history.

Commands are case-insensitive. Use IDs or names as shown.
