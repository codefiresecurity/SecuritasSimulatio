Available Commands

Use these to interact with the MITRE ATT&CK database:

  • ttp id <ID> Get details for a TTP (e.g., ttp id T1059)
  • ttp search <term> Search TTPs by name/keyword (e.g., ttp search phishing)
  • ttp detail <ID> Detailed TTP info (e.g., ttp detail T1059)
  • recommend <ID(s)> Log sources for TTPs, comma-separated (e.g., recommend T1059,T1589)
  • group_ttps <Group ID(s)> TTPs for groups, comma-separated (e.g., group_ttps G0007,G0059)
  • graph <ID> Relationship graph (e.g., graph G0007)
  • create tabletop Start a tabletop exercise (e.g., create tabletop)

Note: IDs can be TTPs (Txxxx), Groups (Gxxxx), Software (Sxxxx), or Campaigns (Cxxxx). Tabletop commands are interactive.
