## Narrative
The cybersecurity exercise simulates an advanced persistent threat campaign targeting a major financial institution, leveraging sophisticated social engineering and multi-stage attacks to achieve stealthy access over time. The group G0073 uses the T1218.011 DGA technique for creating domain names that evolve regularly beyond conventional detection methods. This is followed by a spear phishing attack (T1033) against specific employees, leading to unauthorized access within the network—marked as intrusion events I-I002 and G-G0074 in our logs.
The subsequent use of T1189 - Fileless Malware leads to lateral movement with an initial foothold established by exploiting a zero-day vulnerability (T1564) within Office 365, which is then used as the jumping point for further propagation across systems.
A sophisticated credential dump operation via T1027.013 - Memory Dump Utilization follows to extract user credentials from memory artifacts without leaving traditional traces on disk storage—an exercise in steganography (T1588) within PureStorage Network Manager Systems, designed as a covert channel for data exfiltration and command & control traffic.
This attack sequence culminates with the use of T1059 - Command Execution to execute malicious binaries on compromised hosts while avoiding detection by implementing obfuscated PowerShell commands (T1082). The final stages involve covert data exfiltration via a customized steganography tool using image files as carrier media and the establishment of persistent backdoor capabilities for future access without additional user interactions.
The exercise reflects an evolving threat landscape where attackers constantly adapt their methodologies to bypass security measures, requiring vigilant monitoring systems capable of detecting sophisticated TTP combinations in real-time environments like this simulation. The ultimate goal is enhancing the skills and tactics used for defending against such complex cybersecurity threats within a controlled setting where all actions can be analyzed without consequences to an organization's actual infrastructure integrity.
